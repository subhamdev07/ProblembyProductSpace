## 4. Environment Loading & Lifecycle Architecture

1. **Deterministic Loading:**
   The application loads environment variables through `dotenv.load_dotenv(override=True)` inside `src/core/config.py`. This guarantees that workspace-level overrides take precedence over ambient shell variables.
2. **Strict Typings via Pydantic:**
   All configuration blocks are mapped into frozen Pydantic dataclasses (`NVIDIAConfig`, `BodhanOCRConfig`, and `Settings`). Type conversions (such as converting string floats to native Python `float` or `int`) are automatically checked at instantiation.
3. **Fail-Fast Bootstrapping:**
   If an API key is missing or set to an invalid placeholder (e.g., `""`, `"your_nvidia_api_key_here"`, or `"nvidiaapi"`), the initialization immediately raises typed exceptions (`LLMConfigurationError` or `OCRConfigurationError`), blocking incomplete runtime execution.

---

## 5. Secret Handling and Masking Safeguards

- **Masking Routine:** Implemented in `src/core/security.py` via `mask_secret(secret: str) -> str`. Secrets exceeding 8 characters display the first 4 and last 4 characters separated by ellipses (`nvap...VArV`); shorter strings are masked with asterisks.
- **Request Header Sanitization:** `sanitize_headers()` strips and replaces sensitive authorization tokens before any request headers are printed or logged.
- **No Git Exposure:** Absolute Git prohibitions are strictly enforced. No `.env` files, credentials, or commit logs have been touched or tracked by Git.
- **Console & Report Safeguards:** Automated verification tests and Markdown reports write exclusively masked values (`nvap...VArV`, `sk-A...ShRQ`), guaranteeing zero credential leakage across all artifacts.
