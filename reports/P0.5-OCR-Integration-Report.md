## 1. Executive Summary

The **Bodhan Indic-OCR** service has been integrated to provide robust optical character recognition for scanned, image-based, or non-digital educational documents (e.g., textbook scans, diagrams, handwritten notes, printed test papers). 

### Architectural Boundary:
- **Strict Separation of Concerns:** Bodhan Indic-OCR is solely responsible for transforming document images into structured text. It **does not perform curriculum reasoning or LLM generation**.
- **Separation from LLM:** Bodhan OCR never invokes NVIDIA Nemotron; NVIDIA Nemotron never invokes Bodhan OCR. Downstream coordination is handled by the `DocumentProcessor`.
- **Hybrid Ingestion Pipeline:** Digital PDFs with selectable text are processed natively using PyMuPDF (`fitz`), while scanned or diagram-heavy pages are converted to PNG images at 300 DPI and routed to Bodhan Indic-OCR.
- **Fault-Tolerant Page Processing:** A single OCR page failure does not invalidate the entire document; partial extraction states (`PARTIAL_SUCCESS`) are captured with fine-grained error diagnostic metadata.

### Reference Request Format:
```python
b64 = base64.b64encode(open("block.png", "rb").read()).decode("utf-8")
headers = {"Authorization": f"Bearer {api_key}"}
payload = {
    "model": "indic-ocr",
    "messages": [
        {
            "role": "user",
            "content": [
                {
                    "type": "image_url",
                    "image_url": {
                        "url": "data:image/png;base64," + b64
                    }
                }
            ]
        }
    ]
}
resp = requests.post("https://api.bodhan.ai/v1/chat/completions", headers=headers, json=payload, timeout=120)
```

## 4. Error Handling & Edge Cases

1. **Missing / Placeholder API Key:** If `BODHAN_API_KEY` is empty, digital text extraction still succeeds; scanned pages are marked `FLAGGED_FOR_REVIEW` (`OCR_UNCONFIGURED_FALLBACK`) rather than crashing the pipeline.
2. **Authentication Failures (401 / 403):** Normalized into `OCRAuthenticationError` and halted immediately without wasting retry quota.
3. **Rate Limits (429):** Retried up to 2 times with exponential backoff ($2^{\text{attempt}}$ seconds).
4. **Confidence Score Policy:** If Bodhan API does not return a confidence score in `choices[0]`, confidence is explicitly set to `None` (**Zero fabrication policy**).
5. **Partial Failures:** If page 2 fails due to a network glitch, pages 1 and 3 are retained and the document status is set to `PARTIAL_SUCCESS`.
